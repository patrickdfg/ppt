# 말씀 자막

한글 설교 원고를 읽어 저장된 템플릿으로 자막 파워포인트를 만드는 사이트.

주소: https://patrickdfg.github.io/ppt/

## 사용

1. HWP 5 / HWPX / UTF-8 TXT 원고를 선택한다.
2. 파란색 → 아래 자막, 녹색 → 말씀 전체 화면으로 분류된 문단을 확인한다.
3. 성구·화자·줄바꿈을 수정하고 PPT를 내려받는다.

검정 글씨는 기본으로 제외된다. ‘제외된 문단도 보기’에서 자막으로 바꿀 수 있다.
장절이 있는 색상 문단은 성구로 분류한다. 자동 분류 결과는 반드시 확인한다.
암호·배포용 HWP, HWP 3, PDF, 사진·도표 자동 배치는 지원하지 않는다.
원고에 그림이 있으면 화면에서 알린다. PPT에서 직접 추가한다.
누적 공개를 선택하면 편집한 한 줄씩 누적한 별도 슬라이드가 만들어진다.

## 템플릿 저장

- 기본 템플릿 `assets/template.pptx`는 GitHub에 저장되어 모든 기기에서 사용한다.
- 사용자가 바꾼 템플릿은 IndexedDB에 저장되어 **같은 브라우저에서 재사용**한다.
- 다른 기기로 자동 동기화하지 않는다. 브라우저 데이터를 지우면 개인 템플릿도 지워진다.
- 사용자 템플릿은 첨부 스킬 템플릿의 예시 슬라이드 번호·레이아웃 구조를 유지해야 한다.
- 모든 기기에 공통으로 쓸 기본 템플릿은 저장소의 `assets/template.pptx`를 교체한다.

## 원고 처리와 배포

공개 저장소지만 원고·완성 PPT는 업로드하거나 커밋하지 않는다.
Pyodide 0.27.7을 브라우저 Web Worker에서 실행해 기기 메모리에서 처리한다.
처음 도구를 받을 때 인터넷이 필요하고 시간이 걸릴 수 있다.
런타임은 고정 버전 jsDelivr에서 받으며 원고를 보내는 API·분석·광고는 없다.
원고 내용은 새로고침하면 사라진다. 완성 파일은 내려받아 보관한다.

GitHub Actions는 테스트 후 사이트 파일만 Pages에 배포한다.
GitHub Settings → Pages → Source는 GitHub Actions로 설정한다.

## 개발

`python -m http.server 8000` 후 http://localhost:8000 에서 확인한다.
`python -m unittest discover -s tests -v`

`reference/`는 사용자가 제공한 클로드 스킬의 원본 참고 자료다.
`engine.py`는 그 PPT 텍스트·색·자막 분할 함수를 사용하고, 클로드 전용 도구 의존 없이
슬라이드 복제·관계 정리·PPTX 저장을 처리한다.
HWP 5 기본 레코드와 HWPX 색상을 읽는다. 복잡한 원고는 결과를 확인해야 한다.
`vendor/olefile.py`는 olefile 0.47, BSD 라이선스다.

원고와 비밀값은 저장소에 올리지 않는다. 작업 시작 전 pull, 완료 후 commit/push한다.
